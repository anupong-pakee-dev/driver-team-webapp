# คู่มือเจ้าของ / แอดมินขาย

หลังบ้าน: `https://<โดเมน>/admin` · เจ้าของ (owner) ทำได้ทุกอย่าง · แอดมินขาย (sales) ทำใบเสนอราคา/ดูการจอง/ตรวจสลิปได้ แต่ **อนุมัติเงิน ส่วนลดเกินเพดาน ราคา ตั้งค่า และเอกสาร ไม่ได้**

## ทุกเช้า: กล่องงานวันนี้ (`/admin`)

เปิดหน้าแรกแล้วไล่ทุกกล่องจนว่าง — ทุกเรื่องที่รอคนตัดสินใจรวมอยู่ที่นี่:

| กล่อง | ทำอะไร |
|---|---|
| รอเลือกคนขับ | ไม่มีคนขับผ่านเกณฑ์/ทุกคนปฏิเสธ → เปิดการจอง เลือกคนขับเอง (ต้องใส่เหตุผลถ้า override) |
| สลิป/เงินรออนุมัติ | สลิปที่ระบบตรวจไม่ผ่านอัตโนมัติ, รับเงินแบบ manual, คืนเงิน → ตรวจแล้วอนุมัติ/ปฏิเสธ |
| ส่วนลดรออนุมัติ | แอดมินขายให้ส่วนลดเกินเพดาน → อนุมัติ = ส่งใบเสนอราคาใหม่ให้ลูกค้าทันที |
| เอกสารรอตรวจ / ใกล้หมดอายุ | เปิด `/admin/documents` เทียบรูปกับข้อมูลที่กรอก → อนุมัติ/ตีกลับพร้อมเหตุผล |
| payout รอโอน | โอนเงินจริงในแอปธนาคาร → อัปโหลดหลักฐาน → กด "โอนแล้ว" (แก้ไม่ได้หลังกด) |
| เหตุการณ์/ร้องเรียน | ปิดเรื่องพร้อมผลสรุป — งานที่มีร้องเรียนเปิดอยู่จะไม่ปล่อยเงินคนขับ |
| ข้อความส่งไม่ออก | ดูที่ `/admin/system` → ลองส่งใหม่ |

## งานขาย

1. ลูกค้าขอราคาเองใน LINE หรือแอดมินสร้างที่ **ใบเสนอราคา → สร้าง** (ระบบคิดราคาจากตารางราคา + ระยะทาง)
2. ส่วนลด: ใส่เหตุผลทุกครั้ง · ต่ำกว่าราคาพื้น (floor) ทำไม่ได้ · เกิน `admin_max_discount` ต้องให้เจ้าของอนุมัติ
3. ลูกค้ากดยอมรับ → จ่ายมัดจำ (PromptPay QR/สลิป) ภายในเวลาที่กำหนด ไม่งั้นการจองหมดอายุเอง
4. จ่ายแล้ว → ระบบเสนองานคนขับที่ผ่านเกณฑ์ ณ วันงานตามคิว → คนขับรับ → ลูกค้าได้ข้อความยืนยัน

ยกเลิก: กดในหน้าการจอง ระบบแสดงยอดคืนตามนโยบาย (>48 ชม./24–48/<24) ก่อนยืนยัน · การคืนเงินต้องเจ้าของอนุมัติและโอนเอง

## คนขับและรถ

- **คนขับ → เชิญ**: กรอกชื่อเล่น ชื่อจริง เบอร์ → ได้ลิงก์ ส่งทาง LINE ส่วนตัว (ใช้ครั้งเดียว 72 ชม.)
- ตรวจเอกสารคนขับ + รถ ให้ครบก่อน — รถรับงานได้เมื่อ **ประเภทจดทะเบียนอยู่ในรายการที่ ขบ. ยืนยัน** (`/admin/compliance`) และเอกสารไม่หมดอายุ ณ วันงาน
- บล็อก/ระงับผู้ใช้ที่ `/admin/users` มีผลทันที (session ถูกตัด)

## เงิน

- `/admin/bookings` ดูสถานะเงินทุกการจอง · ใบเสร็จออกอัตโนมัติเมื่อยืนยันเงิน เลขต่อเนื่องไม่ข้าม
- `/admin/payouts` ระบบสร้างรายการรอโอนทุกวันจากงานที่จบแล้ว · ตรวจยอดต่องานก่อนโอน
- `/admin/reports` export CSV (เปิดใน Excel ได้ ภาษาไทยไม่เพี้ยน) ส่งนักบัญชีรายเดือน

## แอด

1. `/admin/ads` → สร้างแคมเปญ (slug, แพลตฟอร์ม, UTM) → ได้ลิงก์ `/go/{slug}` ไปใส่ในแอด
2. landing แต่ละบริการ เผยแพร่ได้หลังติ๊กเช็กลิสต์ครบ (ประกันจริง ตรวจประวัติจริง ราคาจริง ไม่ใช่ทัวร์ มีสิทธิ์ใช้รูป ช่องทางของบริษัท)
3. กรอกค่าแอดรายวัน/สัปดาห์ → รายงานแสดงต้นทุนต่อการจองแยกแพลตฟอร์ม

## ราคาและตั้งค่า (เจ้าของเท่านั้น · ทุกการแก้ต้องใส่เหตุผล · ดูย้อนหลังที่ `/admin/audit`)

- `/admin/prices` ราคาตั้งต้น / ราคาพื้น / กม.-ชม.ที่รวม ต่อประเภทรถ × บริการ · แก้แล้วใช้กับใบเสนอราคาใหม่เท่านั้น
- `/admin/settings` มัดจำ % · นโยบายยกเลิก · ค่าคอม · ระยะเวลาต่าง ๆ · ข้อมูลบริษัท/PromptPay · ข้อตกลงลูกค้า/คนขับ (เปลี่ยนเวอร์ชัน = ทุกคนต้องยอมรับใหม่)

## ระบบ (`/admin/system`)

- งานอัตโนมัติแต่ละตัว: รันล่าสุดเมื่อไร สำเร็จไหม — ขึ้นสีแดง = เกินรอบที่ควรรัน แจ้งผู้ดูแลระบบ
- ข้อความ LINE ที่ส่งไม่ออก: กดลองใหม่ได้ (ลูกค้าบล็อก OA = ส่งไม่ได้ ให้โทรแทน)
- ระบบล่ม/ปิดปรับปรุง: ผู้ดูแลเปิด `MAINTENANCE_MODE` → ลูกค้าเห็นหน้าแจ้งพร้อมปุ่มทัก LINE OA → รับงานทางแชตชั่วคราว แล้วค่อยลงระบบย้อนหลัง

## ความปลอดภัย

- อย่าแชร์รหัสผ่าน · login จากเครื่องใหม่ เจ้าของจะได้แจ้งเตือน LINE — ถ้าไม่ใช่คุณ เปลี่ยนรหัสทันที
- ใส่รหัสผิดหลายครั้ง ระบบล็อก 15 นาที
- ข้อมูลลูกค้า (ชื่อ เบอร์) ห้าม export ออกนอกระบบ · ไฟล์ CSV ไม่มีชื่อ/เบอร์โดยตั้งใจ
