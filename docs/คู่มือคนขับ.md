# คู่มือคนขับ

ทุกอย่างทำใน LINE — เปิดเมนู **งาน · ปฏิทิน · รายได้ · เอกสาร/รถ** จากริชเมนูของ LINE OA บริษัท

## 1. สมัคร (ครั้งเดียว)

1. เจ้าของส่ง **ลิงก์เชิญ** ให้ทาง LINE ส่วนตัว — ใช้ได้ครั้งเดียว ภายใน 72 ชม. (หมดอายุ ขอลิงก์ใหม่ได้)
2. กดลิงก์ → login LINE → อ่านและยอมรับ **ข้อตกลงคนขับ** และการใช้ข้อมูลส่วนบุคคล
3. เมนู **เอกสาร/รถ** → ส่งเอกสารคนขับ: บัตรประชาชน · ใบขับขี่สาธารณะ (เลขที่ ประเภท วันหมดอายุ) · รูปถ่ายคู่บัตร · หน้าสมุดบัญชี · ผลตรวจประวัติ
4. **เพิ่มรถ** → กรอกทะเบียน ที่นั่ง กระเป๋า แล้วส่ง: เล่มทะเบียน · พ.ร.บ. · ประกันภาคสมัครใจ (ต้องเป็นประเภทการใช้เชิงพาณิชย์/รับจ้าง) · ประกันผู้โดยสาร · ใบเสร็จภาษี
5. รอเจ้าของตรวจ — ผ่านแล้วจะได้ข้อความ LINE ถ้าถูกตีกลับ จะบอกเหตุผล แก้แล้วส่งใหม่ได้

> คนขับจาก Pilot: ข้อมูลชื่อและรถถูกย้ายเข้าระบบแล้ว แต่ **ต้องกดลิงก์เชิญ ยอมรับข้อตกลงฉบับใหม่ และส่งเอกสารใหม่** ก่อนรับงานได้

## 2. รับงาน

- เมนู **ปฏิทิน** → ปิดวัน/ช่วงเวลาที่ไม่ว่าง (ระบบจะไม่เสนองานช่วงนั้น)
- งานใหม่มาเป็นข้อความ LINE → เปิดดูรายละเอียด → **รับ** หรือ **ปฏิเสธ** ภายในเวลาที่กำหนด (ปกติ 15 นาที งานด่วนสั้นกว่า) ไม่ตอบ = ระบบเสนอคนถัดไป
- ระบบเสนองานเฉพาะเมื่อ **ใบขับขี่ ประกัน พ.ร.บ. ภาษี ยังไม่หมดอายุ ณ วันงาน** — เอกสารใกล้หมด ระบบจะเตือนล่วงหน้า ต่ออายุแล้วส่งใหม่ในเมนูเอกสาร
- เตือนก่อนงาน: เย็นวันก่อนงาน (18:00) และ 2 ชม. ก่อนรับ

## 3. วันงาน (เมนู **งาน** → เปิดงาน)

| ขั้น | ทำอะไร |
|---|---|
| ออกเดินทาง | กดเมื่อออกจากบ้าน/จุดจอด (กดได้ก่อนเวลารับไม่เกินช่วงที่กำหนด) |
| ถึงจุดรับ | กดเมื่อถึง — ระบบบันทึกตำแหน่ง (ต้องอนุญาตตำแหน่งใน LINE) |
| รับลูกค้าแล้ว | **ต้องถ่ายรูป** (เช่น ป้ายรับ/ลูกค้าขึ้นรถ) ก่อนกด |
| ส่งถึงแล้ว | กดเมื่อส่งเสร็จ |

- ต้องกดตามลำดับ ข้ามขั้นไม่ได้
- **ติดต่อลูกค้า**: ปุ่มโทร/LINE เปิดให้ใกล้เวลางานเท่านั้น และถูกบันทึกทุกครั้ง ห้ามบันทึกเบอร์ลูกค้าไว้ใช้เอง
- ลูกค้าไม่มา / รถเสีย / อุบัติเหตุ / ของหาย → ปุ่ม **แจ้งเหตุการณ์** ในหน้างาน · เรื่องด่วนมาก กด **ฉุกเฉิน** (โทรหาบริษัท/1669/191)

## 4. รายได้

- เมนู **รายได้** แสดงงานที่ทำแล้ว ยอดรอจ่าย และประวัติการโอน
- ยอดโอน = ค่างานที่ลูกค้าจ่าย − ค่าคอมบริษัท − หัก ณ ที่จ่าย (ถ้ามี) + ค่าทางด่วน/ที่จอดที่เบิกคืน
- เงินปล่อยหลังงานจบ (ลูกค้ายืนยัน หรือครบ 24 ชม. หลังส่งโดยไม่มีร้องเรียน) แล้วเจ้าของโอนตามรอบ พร้อมแนบหลักฐาน
- ค่าทางด่วน/ที่จอด: ส่งรูปใบเสร็จให้แอดมินทาง LINE OA ภายในวันงาน

## 5. ข้อห้าม

- ห้ามรับเงินสด/โอนตรงจากลูกค้า (ยกเว้นบริษัทแจ้ง) · ห้ามรับงานลูกค้าบริษัทเป็นงานส่วนตัว
- ห้ามให้คนอื่นขับแทน ห้ามเปลี่ยนรถเองโดยไม่แจ้ง
